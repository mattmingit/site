Welcome to my website!
This is a brief introduction to me and the website itself.

I'm Matteo and I'm passionate about finance and computer science. You'll find more information [here](../../about). 

I made this website to share my works and to get in touch with people. 

I designed and coded the website by my self using [Astro](https://astro.build/).

The website is composed by multiple pages:
1. **projects**: it lists different stuff I create or work on to show my knowledge and skills.
2. **about**: it contains information about myself.
3. **blog**: this is a little blog I write just to express thoughts and exercise writing.
4. **fun**: it contains small, fun and quick code scripts that I practice and have fun with.

You can interact with the website using the terminal displayed in the home page or navigate through it in a more traditional way.

I hope you will enjoy it and if you have questions or find bugs feel free to reach out!
